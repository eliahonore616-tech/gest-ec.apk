Gestion des minervals

Installer sur Android
  1. Ouvrez le fichier téléchargé (notification ou dossier « Téléchargements »).
  2. Si Android le demande, autorisez l’installation depuis cette source.
  3. Appuyez sur « Installer ».
Installer sur Windows
  1. Ouvrez le fichier téléchargé.
  2. Si Windows affiche un avertissement : « Informations complémentaires » puis « Exécuter quand même ».
iPhone / iPad : il n’existe pas d’APK. Ouvrez la version web, puis Partager → « Sur l’écran d’accueil ».
